# Zapret Desync

Обход DPI-блокировок на Android без root: Discord, YouTube и другие сайты.

Приложение не меняет системные настройки и не требует root: весь трафик
заворачивается в локальный SOCKS-туннель, а `ciadpi` разбирает и «ломает»
сигнатуры DPI.

**Zapret Desync** — самостоятельное приложение. Оно не связано с
OpenCode Freedom и устанавливается отдельно, под своим пакетом
`com.oficinaberg.zapretfreedom`.

## Возможности

- VPN-туннель на базе ByeDPI (`ciadpi`) и `hev-socks5-tunnel`;
- стратегии — наборы аргументов `ciadpi`: встроенные, свои, импорт `.bat` с ПК;
- каталог готовых наборов: добавление одним касанием и удаление по одному;
- автоподбор рабочей стратегии с проверкой доступности целей;
- автозапуск при открытии выбранных приложений (через службу спец. возможностей);
- плитки в шторке: обход, автозапуск, выбор стратегии;
- виджет 1×1: включить и выключить обход одним касанием;
- автозапуск после перезагрузки и сторожевой таймер (watchdog);
- автоматическое выключение через заданное время после выхода из приложения;
- русский и английский интерфейс;
- диагностика, журнал, экспорт и импорт настроек.

## Каталог стратегий

Готовые наборы — это наборы **параметров**, а не программа zapret.
Приложение не скачивает и не запускает чужие `.exe`/`.bin`: оно переводит
параметры в аргументы `ciadpi` и запускает только собственный движок.

Можно загрузить свой `.bat` от Windows-версии zapret — параметры
переводятся автоматически, исходный текст сохраняется.

## Сборка

```bash
export ANDROID_HOME=/path/to/android-sdk
./gradlew :app:assembleRelease
```

Требуется JDK 17+, Android SDK 34, Gradle 8.8. Собирается под arm64-v8a.
